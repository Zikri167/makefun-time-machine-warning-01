A program that writes the funniest one-line warning label for a time machine
(120 characters or fewer) to `/output/entry.txt`, for the
[Funniest Time Machine Warning Label](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151)
bounty on make.fun.

## Run

```sh
node main.ts
```

This writes the label to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(`/output/entry.txt` when the variable is not set). Node 22, standard library
only, deterministic, no network.
